Check Management - Check Printing

Print outgoing checks straight onto your bank's check leaves, with the amount in words in Arabic or English, one calibrated layout per bank, and full control over reprints.

What you get

A layout per bank

Paper size, font, date format and the position of every field in millimetres. Link a layout to one or more bank journals, or mark one as the company default.

Amount in words

Commercial Arabic wording as written on Egyptian checks (فقط ... لا غير) or English (... Only), for EGP, USD, EUR, SAR and AED, and the currency's own labels for any other currency.

Safe printing

Only approved checks print. Treasury Officers print once; only a Check Manager can reprint, after a confirmation. Every print is counted and logged in the check history.

How to set it up

  1. Install Check Management - Check Printing from Apps (it needs Check Management). A default layout, Standard Egyptian Check (175 × 80 mm), is created and marked as the company default.
  2. Open the layout: Check Management → Configuration → Check Print Layouts (Check Manager).
  3. Measure one real leaf of the bank's checkbook with a ruler and enter:
    • Check Width / Height in mm; the PDF page size follows automatically.
    • The top and left position (mm from the top-left corner) of the date, payee, amount in figures and amount in words, and the width of the payee and words areas.
    • Font Size, Date Format (for example %d/%m/%Y) and Amount in Words language.
    • Optional Print Crossing text (for example للمستفيد الأول) and its position.
  4. Used For: pick the bank journals whose checks use this layout. Create one layout per bank whose leaf differs.
  5. Print Test Page on plain paper, hold it against a real leaf in front of a light and adjust. If everything is shifted the same way, use Printer Offset Right / Down (negative values move left / up) instead of changing each field.

How to print a check

  1. Create the outgoing check as usual (vendor, amount, due date, bank journal, checkbook leaf). The form now shows the Amount In Words that will be printed.
  2. Get it approved. A check can be printed once it is Approved or Issued, or while in Draft when the company does not require approval.
  3. Load the check leaf in the printer and click Print Check (Treasury Officer). The PDF uses the layout of the check's bank journal, falling back to the company default.
  4. Click Issue to issue the check.
  5. If the leaf jams or prints wrong, a Check Manager can use Reprint Check; the reprint is confirmed first and logged as a copy.

The date printed is the check's due date; the payee is the vendor's name; the figures are framed like #45,000.00#.

Technical notes

  • Depends on sa_check_management; uses num2words for English words. Version 18.0.1.1.0, license OPL-1.
  • Each layout keeps its own report paper format in sync with its size, with zero margins.
  • Adds the Printed event type, print_count and last_printed_date to checks.
